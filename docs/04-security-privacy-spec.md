# QuickPick 安全与隐私规范

## 1. 基本原则

QuickPick 首版采用本地优先和最少保存原则。

默认不保存：

- 用户选中的文本。
- 用户截取的图片。
- AI 返回结果。
- OCR 提取结果。
- 翻译结果。
- 总结结果。

只保存：

- 应用设置。
- 加密后的 API Key。
- 必要的窗口状态。

## 2. AI 上传边界

只有用户主动点击以下功能时，才允许上传数据到配置的 AI 服务：

- 划词翻译。
- 划词总结。
- 截图文字提取。
- 截图文字翻译。
- 输入翻译（手动输入文本）。

禁止：

- 自动上传剪贴板。
- 自动上传截图。
- 自动分析用户屏幕。
- 后台静默调用 AI。
- 保存 AI 请求历史。

## 3. API Key 保存

API Key 不得明文保存到普通配置文件。

优先方案：

- 使用 Windows 本地凭据或 DPAPI 能力加密保存。

最低要求：

- 配置导出和日志中不得出现完整 API Key。
- UI 中默认隐藏 API Key。
- 错误信息不得泄露 API Key。
- 主窗口保存 API Key 时可以同步保存非敏感 AI 设置，但仍不得把 API Key 写入普通设置文件。
- Rust 内存中使用可零化字符串保存 API Key，避免普通 `String` 副本。

## 4. 日志规则

开发日志和运行日志都不得记录敏感内容。

禁止记录：

- 完整 API Key。
- 用户选中文本原文。
- 截图图片内容。
- AI 请求 payload。
- AI 返回全文。

允许记录：

- 功能是否成功。
- 错误类型。
- 请求耗时。
- 模型名称。
- 非敏感配置状态。

## 5. 剪贴板规则

划词读取可能需要临时使用剪贴板时：

- 剪贴板兜底默认开启以保持划词兼容，用户可在设置页关闭。
- 操作前尽量读取并保存原剪贴板内容。
- 获取选区后尽量恢复原剪贴板。
- 临时复制只允许在 UIAutomation 直接取词失败后作为兜底，不得优先覆盖剪贴板。
- 只有用户明确点击复制时，才允许覆盖剪贴板。
- 如果恢复失败，必须尽量避免二次破坏，并可提示用户。

截图复制时：

- `Alt+3` 只允许进入框选流程，不应立即覆盖剪贴板；托盘“区域截图”和主窗口截图按钮入口保持撤回。
- 只有用户完成框选并点击横条菜单“复制”后，才允许把所选区域图片写入剪贴板。
- 点击横条菜单“提取”或“翻译”不应覆盖剪贴板。
- 原生区域截图复制只允许在用户点击“复制”后写入剪贴板，不保存截图文件。

截图 AI 时：

- 只有用户完成框选并点击横条菜单“提取”或“翻译”后，才允许读取所选区域并上传到用户配置的 AI 服务。
- AI 配置不完整时，必须先显示配置提示，不读取截图区域，不发起网络请求。
- AI 结果只显示在独立原生结果弹窗和当前内存状态中，关闭弹窗或清空状态后不再保留。
- 翻译结果弹窗切换源语言、目标语言或方向时，只复用当前弹窗生命周期内的原始文本或截图字节重新请求，不把文本、截图或结果写入历史文件。
- 输入翻译弹窗切换语言或方向时，只复用当前弹窗生命周期内的输入文本重新请求，不把输入文本或结果写入历史文件。
- 开发日志不得记录 OCR 原文、翻译结果或截图内容。

## 6. 本地文件规则

首版不保存截图文件。

临时文件原则：

- 能在内存处理就不落盘。
- 必须落盘时使用系统临时目录。
- 完成后尽快清理。
- 不把临时图片放入项目目录或用户文档目录。

## 7. 网络请求规则

AI 请求必须：

- 只使用用户选择的供应商和配置。
- 使用用户配置的 `base_url`。
- 使用用户配置的模型。
- 设置请求超时。
- 只发送完成当前功能所需的最小内容。
- 对错误做清晰提示。

不允许：

- 遥测。
- 未经说明的第三方请求。
- 自动更新前静默下载大文件。
- 外部 AI 服务使用明文 HTTP。

供应商默认值规则：

- 文本模型和视觉模型分别保存供应商、Base URL、模型名称和 API Key。
- 输入模型独立保存供应商、Base URL、模型名称和 API Key；输入翻译只使用输入模型配置，不复用或回退到文本模型/视觉模型配置。
- 选择 DeepSeek、小米 MiMo、Kimi、GLM、MiniMax 或 Qwen 作为文本模型时，应用可以提供默认 Base URL 和默认模型，减少手动配置错误。
- 选择 DeepSeek、小米 MiMo、Kimi、GLM、MiniMax 或 Qwen 作为视觉模型时，应用可以提供默认 Base URL 和默认模型。
- 用户手动填写 Base URL 后必须以用户填写值为准。
- 小米 MiMo 的 `tp-` Key 在未手动填写 Base URL 时可自动使用 Token Plan 默认地址。
- 旧版单 API Key 只兼容迁移为文本模型 Key；视觉模型 Key 需要单独保存，避免旧文本模型配置直接调用视觉接口。
- AI 响应体上限为 2 MiB，超过上限立即停止解析。

## 8. 权限与系统集成

QuickPick 需要的系统能力：

- 全局快捷键。
- 托盘常驻。
- 开机自启。
- 读取当前选区。
- 剪贴板访问。
- 截图。
- 默认浏览器打开搜索。

实现时应尽量使用 Tauri 官方插件和 Windows 标准能力，不做注入式或高风险全局行为。

WebView 与窗口权限：

- 启用严格 CSP，不保留 `csp: null`。
- 不使用 `core:window:default` 等宽泛权限，只声明实际需要的窗口权限。

## 9. 第三方代码边界

截图模块允许参考 Snow Shot 可用实现，但必须遵守：

- 引入前确认目标 commit 的许可证和文件来源。
- 保留必要的版权和许可证声明。
- 许可证不清楚时只做等价重写，不复制源码。
- 不引入超出 MVP 的滚动截图、标注、贴图、历史记录、录屏或插件代码。
- 参考项目代码不得改变 QuickPick 的隐私默认值：不保存截图历史、不自动上传截图、不记录截图内容。

## 10. 用户可控

设置页必须让用户能：

- 修改或关闭开机自启。
- 修改快捷键。
- 修改 AI 配置。
- 清除 API Key。
- 理解“不会保存历史”的默认策略。

开机自启只使用当前用户级启动项，不要求管理员权限；关闭后应删除 QuickPick 对应启动项，不保留额外后台计划任务。

## 11. 安全验收

首版验收时必须确认：

- `scripts/security-audit.ps1` 通过 `pnpm audit` 和 `cargo audit`。
- 配置文件中没有明文 API Key。
- 开发日志中没有用户内容。
- AI 功能只在用户点击后触发。
- 关闭结果弹窗后不会保留可见敏感内容。
- 程序退出后不残留截图临时文件。
