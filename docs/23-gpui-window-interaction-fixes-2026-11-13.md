## V-04：标题栏移动

锁定版本 `gpui-pre-windows 0.3.12` 未覆盖 `PlatformWindow::start_window_move` 的默认空实现。设置品牌区域、划词空白与输入/结果标题区改用 GPUI 的 `WindowControlArea::Drag`，由 Windows 后端返回 `HTCAPTION` 并进入原生移动。按钮和语言控件继续阻止鼠标按下冒泡；不新增后台线程或同步发送移动循环消息。

## V-05：四角缩放

Windows 子类钩子对具有 `WS_THICKFRAME`、非最大化/最小化的普通窗口补齐八方向 `WM_NCHITTEST`。物理坐标按窗口 DPI 转换：边带 8 DIP、角区 14 DIP，角区优先；负屏幕坐标和窗口外点均有纯函数覆盖。原生缩放按下交给 `DefWindowProcW`，避免被客户区控件消费。最小尺寸仍由既有窗口后端约束。

截图遮罩使用独立安装入口，不增加边缘命中或移动区域，不改变框选、提交、隐藏和捕获链。新增进程自有隐藏窗口测试验证八方向及遮罩排除；不显示窗口、不捕获、不读取剪贴板。

## V-06：静止透明与材质切换

源码中存在两项风险：Mica 使用 DWM backdrop、Acrylic 使用 accent policy，原切换路径未互相清理；原窗口底色、卡片及输入框又叠加各自较高 alpha，使静止表面接近不透明。这些是修复依据，尚不能据此证明用户实屏异常的完整根因。

- 每次应用材质前清理两种原生背景状态，再启用当前材质；拖动结束按当前有效外观恢复。
- 配置不透明度只用于窗口根表面，保留原 `opacity × 0.92` 底色映射。普通卡片、输入框及默认按钮背景透明，保留边框、前景与交互状态；不对文字或整棵控件树施加 opacity。
- 截图工具栏仍为独立高可读玻璃面板，遮罩根始终透明；句柄保留独立实色。外观草稿的预览、保存、隐藏回滚和业务隔离不变。
- 不修改配置结构、Cargo.lock、模型/密钥/HTTP、DPAPI、截图编码或剪贴板复制。Mica 的壁纸材质与 Acrylic 的背后模糊分别验收，不能要求两者呈现相同效果。
