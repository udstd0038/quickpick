# QuickPick 产品需求文档

## 1. 产品定位

QuickPick 是一款运行在 Windows 11 上的轻量划词与截图 AI 工具。

它常驻后台，通过全局快捷键在系统任意位置处理两类内容：

- 选中的文本：复制、翻译、总结、搜索。
- 截取的图片：复制、OCR 提取、OCR 后翻译。
- 手动输入文本：`Alt+4` 呼出输入翻译弹窗，输入文本后调用独立的输入模型翻译。

首版目标不是做大型截图套件，而是做一个稳定、安全、低打扰的 MVP，让用户可以快速把屏幕上的文字或图片交给剪贴板、浏览器或 AI。

## 2. 目标用户

- 不懂代码但希望提升阅读、搜索、翻译效率的 Windows 11 用户。
- 经常在浏览器、PDF、聊天软件、文档、图片中处理文字的人。
- 重视本地隐私，不希望工具自动保存大量剪贴板或截图历史的人。

## 3. MVP 范围

### 3.1 划词功能

用户在任意软件中选中文本后，按默认快捷键 `Alt+2` 呼出横条菜单。

菜单包含：

- 复制：复制当前选中文本。
- 翻译：调用 OpenAI 兼容文本模型，将选中文本翻译为简体中文。
- 总结：调用 OpenAI 兼容文本模型，用简体中文总结选中文本。
- 搜索：调用系统默认浏览器，使用默认搜索引擎搜索选中文本。

选中文本读取策略：

- 优先使用 Windows UI Automation 读取当前选区。
- 如果读取失败，使用临时复制方案获取文本，并尽量恢复原剪贴板内容。
- 如果仍失败，显示明确错误提示。

### 3.2 截图功能

用户按默认快捷键 `Alt+3` 进入区域截图。

首版只做拖拽区域截图：

- 按下快捷键后进入截图遮罩。
- 用户拖拽选择区域。
- 完成后显示截图预览窗口。
- 预览窗口右下角出现横条菜单。

菜单包含：

- 复制：复制图片到系统剪贴板。
- 提取：调用视觉模型识别图片上的全部文字，并在结果弹窗中显示。
- 翻译：调用视觉模型识别图片文字并翻译为简体中文，在结果弹窗中显示原文与译文。

### 3.3 结果展示

所有 AI 结果使用轻量结果弹窗显示。

结果弹窗必须包含：

- 标题：例如“翻译结果”“总结结果”“文字提取结果”。
- 主体结果文本。
- 复制按钮。
- 关闭按钮。
- 请求失败时的错误说明。

首版不自动覆盖用户剪贴板，只有用户点击复制结果时才写入剪贴板。

### 3.4 基础系统功能

- 系统托盘常驻。
- 启动后默认静默常驻，不主动弹出主页面。
- 托盘右键菜单。
- 开机自启动开关。
- 快捷键映射设置。
- OpenAI 兼容 API 配置。
- 跟随系统暗黑模式，可手动切换。

## 4. 明确不做

首版不做以下功能：

- 滚动截图。
- 截图标注工具。
- 截图贴图或固定到屏幕。
- 文本/截图/AI 结果历史记录。
- 云同步。
- 插件系统。
- 图片翻译结果覆盖回原图。
- 跨平台支持。

这些功能可以进入后续版本讨论，但不能挤进首版 MVP。

## 5. 成功标准

首版完成后应满足：

- 在 Windows 11 上能稳定启动并常驻托盘。
- 启动和开机自启后不弹出主页面；只有通过托盘右键“设置”才显示设置页。
- `Alt+2` 能呼出划词菜单，并完成复制、搜索、翻译、总结。
- `Alt+3` 能完成区域截图、预览、复制、OCR、图片翻译。
- `Alt+4` 能呼出输入翻译弹窗，完成手动文本翻译，并支持源语言、目标语言和翻译方向切换。
- AI 配置错误、网络错误、模型不支持等失败场景有清楚提示。
- 不保存用户选中文本、截图、AI 结果历史。
- 常驻状态无明显 CPU 占用，内存占用保持轻量。
- 用户能通过设置页修改快捷键、AI 配置、开机自启和主题。

## 6. 参考项目边界

参考项目只借鉴结构和思路，不复制代码。

- MiniPaste：借鉴轻量常驻、托盘、自启、设置和低占用思路。
- TieZ Clipboard：借鉴 Tauri 2、全局热键、Win11 视觉效果和暗黑模式思路。
- Snow Shot：借鉴区域截图、OCR、AI 调用流程和错误处理思路。

由于参考项目许可证不同，开发中禁止直接复制大量实现代码，避免发布和使用风险。
