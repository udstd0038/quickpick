# QuickPick GPUI 重构方案

日期：2026-11-11  
状态：用户已确认阶段 0 Windows 实机验证通过，已实现全量业务候选；最终功能、打包和性能验收尚待完成，旧 GUI 保留。见 [全量候选验收](11-gpui-full-validation.md)。  
目标平台：Windows 11 x64。  
确定选型：Rust + GPUI + GPUI Component；截图采用实时桌面遮罩，自绘遮罩、选框与拖动控制点。

## 1. 目标、范围与当前事实

### 1.1 重构目标

- 最终发行版彻底移除 Tauri/WebView、React、TypeScript、Zustand 和 Vite GUI 运行链路，改为单一 Rust 桌面应用。
- 保留当前划词、截图复制/提取/翻译、输入翻译、设置、托盘、快捷键、开机自启、主题和八种界面语言。
- 优先复用组件库普通控件；截图选区采用小范围自研，不引入完整图片编辑器。
- 降低浏览器运行时带来的常驻开销，去掉截图预览 PNG/Base64/事件传输链路；不承诺未测量的收益比例或安装包大小。
- 保持既有设置、三套 AI 配置和 Windows DPAPI 密钥文件兼容，不要求用户重新输入密钥。

### 1.2 不进入本次范围

不加入滚动截图、标注、贴图、窗口自动识别、录屏、历史、云同步、插件、流式 AI 输出或 macOS/Linux 产品支持。首版截图只允许在单块显示器内选区，不实现跨显示器拼接。

### 1.3 当前源码基线

- 版本为 0.1.4，桌面实现为 Tauri 2 + React 19，Rust 负责 AI、取词、截图和系统集成。
- 活动窗口为 `main`、`selection`、`result`、`input`、`screenshot_overlay`；独立截图预览不在当前入口中。
- 设置窗口启动时创建且隐藏；其他窗口经 `get_or_create_window` 首次创建，之后隐藏复用，并非五个窗口全部启动预创建。
- 截图预览当前使用 xcap 整屏捕获、PNG/Base64、Tauri 事件和 react-image-crop；确认操作后再捕获所选区域。
- `ai.rs`、`selection.rs` 和截图核心有可复用逻辑；设置、密钥、热键和应用编排仍有 Tauri 耦合。
- 现有架构/UI/迁移文档含原生 Win32 与 WebView 路径并存的过期或未决描述。实施时按 AGENTS.md 判定冲突，不把这些表述直接当成当前实现。

本方案记录未来目标，不宣称现有架构已改变。进入实现阶段时才同步有效架构、UI、隐私、测试和工作流规范；本次不覆盖这些现状文档。

## 2. 技术选型与体积控制

### 2.1 选型表

| 层级 | 当前 | 目标 |
| --- | --- | --- |
| 界面与窗口事件循环 | Tauri + WebView | GPUI 主线程事件循环 |
| 普通控件 | React/HTML、自定义控件 | GPUI Component，经 GPUI Kit 接入 |
| 状态 | hooks、Zustand、Rust 快照 | GPUI Entity + Rust 会话状态 |
| UI 通信 | invoke、事件、JSON 快照 | 类型化 Rust 调用和完成事件 |
| 样式 | CSS/Tailwind | GPUI 样式 API、组件主题与项目令牌 |
| AI 网络 | reqwest + Tauri 异步运行时 | 保留 reqwest，使用显式 Tokio 运行时 |
| 屏幕捕获 | xcap | 保留 xcap，仅确认后捕获区域 |
| 图像处理 | image、Base64 | 保留 image；Base64 仅用于 AI 请求等实际需要的边界 |
| 密钥 | Windows DPAPI | 保留 DPAPI 与 Zeroizing |
| 托盘、菜单 | Tauri API | tray-icon + muda，注册在 Windows UI 线程 |
| 全局快捷键 | Tauri 插件 | global-hotkey；保留 Win32 按键释放检测 |
| 单实例 | Tauri 插件 | Win32 命名互斥量；第二实例直接退出 |
| 自启动 | Rust 注册表逻辑 | 保留并拆出，与实际发行路径同步 |
| 打包 | Tauri bundle + NSIS | Cargo release + makensis + 便携 ZIP |

不同时维护 GPUI 与 Tauri 的生产事件循环。迁移期间两个可执行文件分别构建、分别运行，只共享无 GUI 业务模块。

### 2.2 版本与依赖规则

- 当前候选工程精确锁定 GPUI Kit `0.9.1`，绑定 `gpui-pre = =0.3.12`，来自 crates.io 并记录于根 Cargo.lock。发布可用性和 Linux 上 Windows GNU 目标交叉检查已确认；阶段 0 Windows 实机可行性已由用户确认，全量候选 MSVC release 与运行验收另行记录。
- 阶段 0 必须验证固定组合的 Windows 编译；如需改用上游修补版本，固定完整 commit 并更新锁文件，不得漂移跟随 main。
- 禁止另行加入不匹配的 crates.io `gpui`；通过 Kit 的重导出使用同一 GPUI 类型。依赖树发现多个 GPUI 后端版本时先处理再继续。
- 其余新增库在阶段 0 选定互相兼容的确切版本并写入锁文件，不使用通配版本。复用现有 crates 的版本优先保持不变，避免 GUI 重构混入不必要升级。
- 不启用 GPUI Fast、JS shell、WebView、语音、语法高亮和语言语法包；不复制组件库 gallery/story 项目作为应用基础。
- 普通控件层并非每个控件都有独立 feature，不能承诺只编译被引用的几个控件。以最终依赖树和链接结果判定。
- 只嵌入需要的 Lucide SVG 和现有应用/托盘图标，不引入完整字体包。系统字体回退覆盖现有八种语言。
- 初始沿用 `opt-level = "z"`、`strip`、`lto = "thin"`、`codegen-units = 1`、`panic = "abort"`，在 Windows release 实测后才改变配置。
- 不使用 UPX 作为默认体积方案。分别报告 EXE、ZIP、安装包、安装后目录、进程私有内存和 GPU 内存。
- 新依赖须完成 Windows 目标依赖树、许可证和安全审计；GPUI/组件源码按其许可证保留声明，不复制许可证不明确的截图项目代码。

## 3. 目标结构、接口与线程模型

### 3.1 Cargo workspace

迁移期在仓库根增加 Cargo workspace，明确列出新 crates，旧 `apps/desktop/src-tauri` 显式排除并通过自身 manifest 构建。

```text
crates/
  quickpick-core/          设置模型、AI、错误、会话和选区几何
  quickpick-platform/      Windows 取词、捕获、DPAPI、路径、热键、托盘、窗口适配
apps/
  quickpick-gpui/          GPUI 启动、普通窗口、实时截图遮罩
  desktop/                迁移期保留旧 Tauri 应用
```

依赖方向：GPUI 应用依赖 core 和 platform；platform 依赖 core；core 不依赖 GPUI、Tauri 或 HWND。最终二进制命名为 `quickpick.exe`。迁移期候选产物单独输出，不覆盖既有 release。

### 3.2 最小接口约定

以下为待实现接口语义，不是现有 API：

| 接口/类型 | 责任 |
| --- | --- |
| `AppPaths` | 注入配置、加密密钥和非敏感窗口状态路径；替代 AppHandle 路径查询 |
| `SettingsRepository` | 加载、归一化、验证和原子保存现有 AppSettings |
| `SecretStore` | 按 Text/Vision/Input 域查询、保存、删除密钥；不得向普通 UI 状态返回现存明文 |
| `SelectionService` | 原前台窗口取词、UIA 优先、剪贴板兜底与恢复 |
| `CaptureService` | 枚举显示器元数据、按全局物理矩形捕获图像、写图片剪贴板 |
| `AiService` | 明确接收配置域、动作、语言和输入；不跨域回退 |
| `WindowCoordinator` | 按窗口角色创建/隐藏、焦点和置顶、非敏感窗口状态 |
| `SessionId` / `RequestId` | 区分窗口生命周期和单次任务，拒绝过期完成消息 |
| `RegionRectPx` | 有符号全局 x/y、无符号 width/height；只允许经校验后捕获 |
| `ScreenshotAction` | Copy、Extract、Translate；显式枚举，未知动作报错 |
| `AppError` | 现有本地化错误键和必要非敏感细节；成功 AI 正文不经过翻译键解析 |

截图选择模型只负责矩形，不直接发网络或写剪贴板。展示层提交动作，业务协调器重新校验并执行。GPUI Entity 保持 UI 线程所有权，不跨线程传递可变 UI 对象。

### 3.3 线程与取消

- GPUI 主线程负责窗口、输入、绘制和轻量状态变化。严禁在其上执行捕获、图像编码、HTTP、UIA 或线程 sleep。
- 全应用只创建一个 Tokio 运行时承载 reqwest；通过 channel 把结果投递回 GPUI，不在 GPUI 线程上 block_on。
- UIA 使用初始化相应 COM apartment 的专用工作线程，保持现有来源窗口、时间预算与剪贴板互斥语义。无法中断的 provider 调用仍不得宣称可硬取消。
- 捕获和编码使用受限阻塞任务；同时只接受一个取词/截图准备操作，避免重复任务争抢焦点。
- 窗口隐藏、会话结束或重新发起请求时递增 ID；HTTP future 可取消时主动取消，已完成或不能立即取消的任务返回后丢弃过期结果。
- 取消不等于远端服务停止处理，也不保证阻塞系统调用立即结束。清理任务持有的敏感输入，不写磁盘历史。

## 4. 普通 GUI 与系统功能迁移

### 4.1 控件与外观

| 当前能力 | GPUI 实现 |
| --- | --- |
| 设置表单 | Input、Select/Combobox、Checkbox/Switch、Slider、Tab、Scroll |
| 划词横条 | Button、Lucide 图标、Tooltip，自定义紧凑横向布局 |
| 输入翻译 | 多行 Input、语言选择、方向切换、Ctrl+Enter |
| 结果窗口 | 可选择复制的文本、滚动容器、复制/关闭/重译按钮 |
| 加载/错误 | Skeleton/Spinner、内联错误与重试，不显示内部线程/请求 ID |
| 自定义 GlassSelect | 组件选择器交互加项目主题；不逐行翻译 CSS |
| 八种语言 | 迁移现有键与字典；Rust 提供等价 `t()` 接口、参数插值和系统语言归一化 |
| 主题 | 项目统一颜色、间距、圆角、透明度令牌，适配组件库主题与系统主题变化 |

保持现有信息结构和操作入口，先核对各窗口外观截图与行为，不借重构进行产品改版。输入法组合期间不把 Enter 当作提交；支持选区、复制粘贴、撤销、光标导航、密码遮蔽及 Tab 焦点顺序。

### 4.2 窗口生命周期

- 启动静默常驻；设置窗口隐藏预创建，其余按需创建并隐藏复用。
- 设置默认和最小逻辑尺寸为 420×600；从隐藏或最小化重新打开重置默认尺寸，不恢复旧设置窗口尺寸。
- 划词 480×58，结果和输入初始 480×460，遵循当前源码；保留可调整大小、置顶开关和拖动能力。
- 划词失焦隐藏并清理。结果/输入窗口的失焦行为以现有前端 pinned 状态逻辑逐项迁移；固定时不因失焦隐藏，显式关闭仍清理内容。
- 主设置窗口关闭转为隐藏；托盘“退出”才退出进程。工具窗口关闭或隐藏清理文本、图像、结果和重译上下文。
- Acrylic/Mica 通过 platform 的 HWND/DWM 适配；普通窗口保留当前选项与透明度。不可用时按现有约定降级并反馈，不静默删除选项。
- 迁移现有拖动时挂起窗口效果、停止后恢复的行为，采用事件与短时任务，避免常驻轮询。截图遮罩不应用 Acrylic/Mica。
- DPI manifest 设置为 Per-Monitor V2，并与 GPUI 清单合并，避免重复清单。远程桌面、软件渲染或显卡初始化失败必须可控失败，不默默启动旧 WebView。

### 4.3 系统集成

- 全局快捷键默认保留 Alt+0/2/3/4；热键录制期间暂停业务触发。修改快捷键先校验，注册失败回滚，避免配置与实际注册不一致。
- 保留按下时记录来源窗口、等待热键全部释放、仅活动菜单发送 Esc、剪贴板兜底和原内容恢复等修复，不用 GUI 重写简化它们。
- 托盘和菜单保持现有入口与本地化，图标使用现有资源。菜单/回调在 UI 线程接入，不在工作线程创建 Windows 菜单。
- 新旧应用共享同一个实例互斥规则。迁移期新应用启动时同时检查旧实例；只允许一个版本注册热键或写配置，不强制终止用户进程。
- 开机自启动保留现有开关与默认值，程序路径正确加引号；安装版只指向安装目录，便携版遵循用户启用时的实际路径。
- 外部搜索保留 URL 校验和长度约束，使用 Windows 标准打开方式，不引入浏览器控件。

## 5. 实时桌面遮罩设计

### 5.1 已确定的产品行为

- 进入框选不捕获屏幕、不创建截图纹理、不编码 PNG/Base64，也不读取截图像素。
- 透明遮罩后方保持实时桌面；选区明亮，选区外暗化。选择期间底层应用仍可能更新，最终捕获的是用户确认后读取的画面，不承诺冻结帧。
- 遮罩自身接收鼠标输入。透明不等于点击穿透；不启用让整窗穿透的扩展样式，禁止把 WS_EX_TRANSPARENT 当成通用半透明开关。
- 只有用户点击“复制”“提取”或“翻译”后才读取所选区域；AI 操作须先确认对应配置完整。配置缺失时不捕获、不上传。
- Esc、右键、失焦、锁屏/挂起和显示器布局变化取消截图。闲置 120 秒取消；活动输入重置计时，计时器仅在截图会话存在时运行。
- 仅当前显示器内选择；默认跟随触发时鼠标所在显示器，无有效鼠标位置时退回主显示器。这是目标行为，当前代码的主显示器选择不能被当作已实现的跟随鼠标。
- 无自动保存、无历史、无后台 AI。屏幕受保护或捕获失败时提示错误，不绕过系统保护。

### 5.2 透明窗口与平台可行性闸门

创建无边框、置顶、不进任务栏的覆盖窗口，按目标显示器完整物理边界定位，包括任务栏，不使用仅工作区大小。首次展示前设置好位置、尺寸和透明背景；不使用捕获屏幕来填充初始帧。

GPUI 的透明填充不自动证明 Windows swapchain/合成链路支持逐像素透明。阶段 0 必须先验证：

1. 绘制 alpha 为 0 的中心，能看到后方实时变化的桌面，而非黑色/白色背景。
2. 半透明矩形正确暗化；透明区域仍能接收完整鼠标事件。
3. 无可见白闪、任务栏遮挡或无故激活其他窗口，混合 DPI 下边界正确。
4. 隐藏后捕获不包含遮罩、选框或工具栏。

优先采用固定 GPUI 版本支持的透明窗口与原生句柄 API。若缺少所需能力，允许 platform 层做最小窗口/合成适配，但必须先证明其与 GPUI renderer 兼容；不能仅靠 SetLayeredWindowAttributes 就宣布可行。

闸门不通过则暂停后续 GUI 替换，保留旧发行版，报告 GPUI 后端限制及所需补丁。不得擅自改成冻结整屏截图、WebView 混合方案或外部截图程序。

### 5.3 自绘层次

| 绘制层 | 内容与默认值 |
| --- | --- |
| 背景 | 完全透明，不使用 paint_image 展示桌面 |
| 遮罩 | 无选区时整屏黑色 alpha 0.35；有选区时画上/下/左/右四个矩形 |
| 边框 | 1 个物理像素，高对比实线，对齐像素网格 |
| 控制点 | 四角与四边中点共八个；可见 8 DIP，命中半径 8 DIP |
| 尺寸提示 | 显示最终物理像素 width×height，不显示屏幕内容信息 |
| 工具栏 | 复制、提取、翻译、关闭，复用组件库按钮、图标和 Tooltip |

使用 GPUI canvas/矩形绘制完成遮罩和选框，文字与工具栏使用普通元素。无遮罩纹理、无自定义 shader、无图像编辑器依赖。工具栏尺寸按本地化内容布局，距选区 8 DIP，优先下方，不足则上方并限制在屏幕内。

鼠标拖动时隐藏工具栏；松开后恢复。工具栏始终优先命中且阻止事件传给选区。屏幕边缘控制点的显示与命中区域限制在窗口内；极小选区优先角点，边中点空间不足时不显示，但保留边线缩放。

### 5.4 状态机与交互

| 状态 | 进入 | 移动/确认 | 结束 |
| --- | --- | --- | --- |
| Preparing | 热键触发并取得捕获入口锁 | 记录来源窗口、显示器、拓扑和 DPI；等待热键释放与菜单清理 | 显示遮罩后进入 Idle |
| Idle | 无有效选区 | 左键按下记录起点，进入 Drawing | 取消退出 |
| Drawing | 空白处按下左键 | 起点与当前点归一化生成矩形，限制显示器边界 | 松开后有效则 Selected，否则恢复按下前状态 |
| Selected | 有效选区 | 控制点/边线开始 Resizing；内部开始 Moving；外部重新 Drawing | 点击动作进入 Submitting |
| Moving | 选区内按下 | 用原始矩形加总位移，保留尺寸并限制边界 | 松开进入 Selected |
| Resizing | 控制点或边线按下 | 固定对侧边/角；跨锚点后归一化并更新方向 | 松开进入 Selected |
| Submitting | 动作已校验并取得提交权 | 禁止重复操作；隐藏并同步后捕获区域 | 结束截图会话，业务任务转交结果窗口 |
| Cancelled | 任意取消路径 | 释放鼠标捕获，隐藏窗口，失效会话和定时器 | 清空选区和任务引用 |

命中顺序为工具栏、最近控制点、边线、选区内部、空白。边线命中宽度为向两侧各 5 DIP；光标对应移动、横纵或对角缩放方向。方向交叉时更新光标，不能保留负宽高。

交互计算使用按下时的矩形、锚点和当前位置，不逐事件累加取整。按下移动超过 3 DIP 才认定拖动；最小有效选区为 8×8 个物理像素。零面积点击不提交，不默认整屏。

首版不加固定比例、吸附、标注或键盘微调。Tab 可进入工具栏，Space 激活焦点按钮，Esc/右键取消；Enter 不设隐含截图动作，避免误触上传。

整个拖动期间持续接收 move/up。优先使用所选 GPUI 版本支持的事件路由；必要时以 Win32 SetCapture/ReleaseCapture 封装同一 HWND。失去捕获时恢复本次按下前选区；失焦则取消整个会话。拖出屏幕时坐标限制边界，松开不得留下拖动状态。

### 5.5 坐标模型

明确区分窗口逻辑坐标、显示器局部物理坐标和桌面全局物理坐标，不把不同单位存进同一个普通 Rect。

```text
画布内 DIP 坐标
  → 乘该显示器窗口的实际缩放因子
  → 显示器内物理像素坐标
  → 加显示器全局物理原点
  → RegionRectPx
```

选区计算使用浮点数；提交时对局部左/上取 floor，右/下取 ceil，再限制到显示器像素边界并计算宽高，最后校验最小尺寸。负坐标只允许在全局原点和 x/y 中出现，不把负值转为无符号。

Windows 物理显示器信息与 GPUI DIP 边界由 platform 统一对齐，不能混用被 DPI 虚拟化的 Win32 坐标。会话中拓扑、目标显示器、分辨率或 DPI 发生变化时取消，而不是继续用旧比例捕获。

### 5.6 确认后的捕获顺序

1. 用会话 ID 防重复，验证动作、矩形、显示器拓扑；AI 操作先验证 Vision 配置与密钥。
2. 复制/冻结必要的矩形和动作元数据，标记 Submitting，释放鼠标捕获。
3. 在 UI 线程隐藏遮罩和其他 QuickPick 工具窗口；此时不显示结果 Skeleton。
4. 等待隐藏命令完成和原生可见性确认，再在后台执行 DwmFlush 作为合成同步手段；原实现的 80ms 可作为初始有界稳定等待，实测后调整。仅返回 hide 成功不构成画面已消失的证明。
5. 捕获前再次检查取消、显示器拓扑及窗口隐藏条件；最多等待 500ms，未满足则报错并不捕获。普通桌面之外的安全桌面切换取消。
6. 用现有 xcap 路径只捕获选区。Copy 只生成剪贴板需要的 DIB/BMP；AI 只生成 PNG，不为所有动作同时编码两种格式。
7. Copy 成功后结束，不自动显示图像预览；AI 取得区域图像后才显示结果窗口并发起网络请求。
8. 失败时在截图窗口已隐藏后展示本地化错误；不以整屏重试，不读取旧划词错误状态，不自动重试 AI 上传。

实时桌面在确认和实际捕获之间可能变化，这是该模式的明确边界；不通过连续录屏或预捕获来弥补。捕获期间图像只留内存，关闭结果窗口后不保留截图重译上下文。

## 6. 设置、密钥与数据兼容

- `AppPaths` 保持当前 Tauri identifier `com.quickpick.desktop` 对应的 Windows 实际配置目录和文件名；阶段 0 在旧 release 上读取并记录非敏感实际路径，不能假设改用 dirs 后路径自动一致。
- 保留 AppSettings 的 JSON 字段、缺省值、加载归一化、供应商规则和旧配置迁移语义；字段删除/重命名不作为 GUI 重构内容。
- 保留 `text_api_key.dpapi`、`vision_api_key.dpapi`、`input_api_key.dpapi` 和旧 `api_key.dpapi` 文本域回退。输入/视觉域不回退到其他域。
- DPAPI 在原用户上下文解密，不能改为机器范围或要求普通运行提权。普通 UI 只显示 configured 状态；用户新输入的密钥也不能进入日志、常规配置或持久 UI 快照。
- 设置保存采用同目录临时文件与原子替换；旧文件解析失败明确报错，不自动用默认值覆盖。仅非敏感配置允许迁移备份，密钥不产生明文备份。
- 热键、开机自启和设置写入视为协调操作；任一步失败恢复原设置和注册状态，并报告非敏感错误。
- 窗口状态仅保存非敏感几何/外观，不保存文本、选区、截图和结果；不沿用 Tauri window-state 插件作为新程序运行依赖。
- 保留当前 AI 输入上限和响应上限：文本 12,000 字符、图片 PNG 8 MiB、响应 2 MiB，以及配置超时规则；HTTPS 和本地/私有网络 HTTP 例外沿用现有校验。
- UI 错误与 AI 成功正文分离，不把含有类似错误键前缀的成功正文误翻译。

## 7. 实施阶段与退出条件

| 阶段 | 交付物 | 必须通过的检查 |
| --- | --- | --- |
| 0：基线与可行性 | 固定依赖组合、最小 GPUI 窗口、实时遮罩样机、旧版性能与兼容基线 | Windows release 编译；透明/输入/隐藏后捕获闸门；中文 IME；Acrylic/Mica；托盘/热键事件循环兼容；路径和密钥兼容 |
| 1：业务解耦 | core/platform、AppPaths、服务接口和任务消息 | 旧应用可通过适配层调用；既有业务测试保留；请求域隔离与文件格式不变 |
| 2：普通界面 | 设置、划词、结果、输入、主题和八语言 | 控件行为、焦点、置顶、隐藏清理、过期请求保护及 Windows 人工验收 |
| 3：截图选区 | 纯几何模型、实时遮罩、八方向缩放、工具栏和提交链路 | 取消不捕获；无配置不捕获；选区像素准确；不截到自身；复制/提取/翻译隔离 |
| 4：系统集成与发行 | 单实例、托盘、自启、NSIS、便携 ZIP、CI | 干净 Windows 安装/升级/卸载/回退；无 WebView 依赖；热键真机测试 |
| 5：性能与切换 | 对比报告、文档同步、新版本候选产物 | 全功能通过；性能/体积回归有解释；候选 Windows release 人工验收后替换正式发行链路 |

每阶段结束保留可构建状态，不一次删除旧 GUI。旧 Tauri 适配器不进入最终 GPUI 依赖树。完成阶段 5 后移除旧应用和仅为前端使用的依赖、脚本、权限配置；保留可回退的 Git tag 与旧安装包，不在新产品中隐藏内置旧实现。

本方案不授权实际发布、部署或覆盖用户安装；后续实施任务先生成可审查候选产物，正式发布按当时用户授权执行。

## 8. 测试与验收

### 8.1 自动化

| 层级 | 关键场景 |
| --- | --- |
| 纯几何单元测试 | 四方向新建、八方向缩放、跨锚点、边界移动、命中重叠、零面积、8px 下限、负原点和取整 |
| 状态与任务测试 | 旧请求晚返回、取消后完成、重复提交、失焦、丢失捕获、拓扑变化、窗口隐藏失败 |
| 服务编排测试 | 进入遮罩/拖动/取消的捕获调用为零；配置错误捕获为零；复制不调用 AI；AI 不写剪贴板；捕获先于结果显示 |
| 配置兼容 | 旧 JSON 加载与保存、三域密钥、旧文本 Key 回退、损坏配置不覆盖、保存失败回滚 |
| GUI 测试 | 工具栏事件不穿透、焦点和 Tab、按钮禁用、主题/语言切换、关闭清理 |
| 现有功能回归 | UIA 优先、剪贴板序号与恢复、热键互斥、供应商请求构造和响应大小限制 |

几何测试包含性质断言：有效选区始终在边界内、宽高非负、移动不改尺寸、取消恢复原值。GUI 模拟测试不能替代真实 Windows 合成与捕获测试。

目标检查命令（仅在相应 crates 和脚本实现后使用）：

```powershell
cargo fmt --all --check
cargo clippy --workspace --all-targets --locked -- -D warnings
cargo test --workspace --locked
cargo build -p quickpick-gpui --release --locked
powershell -ExecutionPolicy Bypass -File scripts\verify-hotkeys.ps1
powershell -ExecutionPolicy Bypass -File scripts\security-audit.ps1
```

旧前端尚未删除期间，原 pnpm test/build 继续覆盖旧发行版；不能用其通过证明 GPUI 已通过。需要对热键和审计脚本中的 Tauri 路径/事件依赖做适配，不能假设原脚本无需修改。

### 8.2 Windows 人工验收矩阵

- 单屏与双屏，100%/125%/150%/200% DPI、混合缩放、负坐标副屏、竖屏和任务栏不同位置。
- 当前支持的普通桌面场景；Firefox、ChatGPT、微信、Steam 中可选文本；菜单激活、不同热键松开顺序、慢复制与剪贴板竞争。
- 截图背景实时变化；选区内透明但能拖动；鼠标移出窗口松开；极小选区、最大选区、屏幕边缘工具栏、多次连续截图。
- 遮罩取消、失焦、锁屏、休眠恢复、显示器热插拔；任何取消路径不上传、不写剪贴板、不残留窗口。
- 用户主动提供的无敏感测试画面包含边缘标尺，验证选区像素边界及截图不包含遮罩。测试图像仅用于人工观察，不纳入 CI 产物或仓库。
- 中文 IME、八语言文案溢出、长文本滚动/选择/复制、密码框、Ctrl+Enter、浅深主题、Mica/Acrylic 与普通透明降级。
- 安装版升级、标准用户权限启动、旧密钥读取、便携路径含空格/非 ASCII、自启路径、第二实例和旧新版冲突。
- Windows 受保护内容、独占全屏或安全桌面无法捕获时，明确失败而非承诺支持；不自动增加权限或切换捕获策略。

### 8.3 性能和体积验收

同一 Windows 设备、相同电源与缩放设置，比较旧版/候选版 release；记录 CPU、GPU、驱动、系统、commit 和构建参数。分别测冷启动、首次弹窗、热复用和全部功能使用后隐藏，不能混为一个常驻值。

| 指标 | 测量方法与目标 |
| --- | --- |
| 常驻内存 | 启动稳定 60 秒及各窗口使用后稳定 60 秒，统计专属进程树 Private Bytes/Working Set；优化目标是下降，下降比例不预设 |
| 空闲 CPU/GPU | 无操作持续 60 秒采样；不得新增持续重绘或高频轮询，相比旧版不得出现持续活动回归 |
| 弹窗响应 | 首次与复用分开，输入触发到首个可交互帧，至少 30 次，报告 p50/p95；目标不劣于旧版 |
| 截图框选 | 4K 屏按下到边框更新、拖动帧耗时；60Hz 环境交互帧 p95 目标不超过 16.7ms，记录丢帧 |
| 捕获动作 | 确认到取得区域图像的本地耗时；不把 AI 网络等待算成 GUI 收益 |
| 内存回收 | 100 次截图开始/取消及确认循环，检查 CPU/GPU 资源是否持续增长；通过资源计数与稳定平台判断泄漏，不能仅要求工作集立即下降 |
| 文件体积 | 比较 EXE、ZIP、NSIS、安装目录；WebView2 系统运行时单列，不算进旧安装包；候选体积若增大须说明来源再决定正式切换 |

上述时延是工程目标，不是已经测得结果。性能回归或未达目标先定位并记录，不通过降低测试场景复杂度来宣布成功，也不以 AI 总响应时间判定 GUI 性能。

## 9. 发行、回退与文档收尾

- 安装产品名、identifier、升级标识、快捷方式和卸载注册沿用现有值。NSIS 模板去除 WebView2/Tauri 专属步骤，保留许可、八语言安装文案和现有有效安装行为。
- 新发行包包含 GPUI 所需运行文件和第三方声明；不能只复制 exe 就假定运行依赖齐全。在未安装开发工具和无 WebView2 的干净 Windows 环境验证。
- 安装前要求应用正常退出，不强制杀进程。保留不含敏感内容的旧安装包与版本 tag；回退恢复旧程序，配置目录和 DPAPI 文件保持兼容，不降级覆盖密钥。
- 自启注册在安装/回退后指向实际程序路径；退出时释放热键、托盘、互斥量和任务。阶段性验证不改动用户正式自启项。
- CI 在 Windows 执行 Cargo 检查、测试、release 和打包；许可证/安全审计独立运行。无桌面 CI 不宣称通过 IME、DPI、透明合成和截图人工验收。
- 性能诊断仅本地可选启用，不加遥测；只记录阶段耗时、错误类型和资源计数，不记录文本、图像、密钥、完整 AI payload 或正文。
- 正式切换时同步 AGENTS.md、README、架构、UI、隐私、测试、开发流程和发行脚本，明确实时遮罩已替代整屏冻结预览，不保留两套相互冲突的现行说明。

## 10. 尚未验证的事实与完成判据

阶段 0 Windows 实机验证已由用户确认通过；全量候选新增业务、混合 DPI 回归、安装升级卸载、性能与最终体积仍须按全量矩阵验收。阶段 0 反馈不替代阶段 5 完成判据。

重构完成需同时满足：

1. GPUI release 覆盖现有全部范围内功能，普通控件可用且八语言无明显溢出。
2. 实时截图遮罩进入、拖动和取消不读取屏幕像素；用户确认后只捕获所选区域，AI 配置不完整不捕获。
3. 所有取消/关闭路径清理敏感状态，旧任务不能覆盖新会话；不保存截图和 AI 历史。
4. 既有设置、三套配置与 DPAPI 密钥兼容，旧程序可回退读取。
5. Windows 目标自动化与人工矩阵通过，性能和体积报告有真实数据及限制说明。
6. 最终发行链路无 Tauri/WebView/Node 运行依赖，安装升级卸载可用，文档与实际行为一致。
