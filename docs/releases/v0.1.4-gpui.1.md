# QuickPick v0.1.4-gpui.1 — GPUI 原生界面预览版

本版基于 Windows visual-fix4 已测源码，将旧版 Tauri / React / WebView 界面重构为 Rust / GPUI 原生界面。应用内部版本仍为 0.1.4，使用独立预发布标签，与已发布的 Tauri v0.1.4 区分。完整验收未完成，保留旧版正式发行；优先使用便携版独立试用，安装包仅供隔离环境验证。

## 重构了什么

- **界面与运行架构**：设置、划词条、结果、输入翻译和截图工具栏迁移至 GPUI。当前候选运行路径不加载 React/Vite 前端或 WebView；仓库保留旧 GUI 作为回退，不能据此宣称旧代码已删除。
- **Rust 分层**：建立 `quickpick-core`、`quickpick-platform` 和 `quickpick-gpui` workspace，分别承载配置/AI/状态编排、Windows 系统集成与原生交互界面。
- **统一视觉**：集中浅深主题、Segoe UI、颜色与控件；保留默认窗口尺寸，加入主题/材质/透明度内存预览、保存提交和隐藏回滚。未保存模型、密钥和快捷键不会因外观预览生效。
- **Windows 窗口交互**：使用原生标题命中实现移动，补齐八方向边缘缩放与 DPI 坐标处理，异步同步恢复后的 GPUI 视口；修复还原裁切风险。
- **截图与剪贴板**：保留实时透明遮罩与显式提交流程，修复 RGB24/BI_RGB 双格式复制链；合成四色 GUI 回读在已测矩形中不含工具栏、边框或额外暗化。
- **配置与隐私**：保持三路 AI 配置隔离、Windows DPAPI、成功正文原样复制及关闭清理。修复英语重置/首次回滚的下拉混合语言；保存与重置等高、滑条跟随主题。
- **交付与验证**：提供独立 GPUI Windows 构建、ZIP/NSIS、许可材料与哈希校验、热键验证和合成夹具。

## 性能：已有改善来自早期 GPUI 同机观察

以下数据是 **Tauri 0.1.3 对比早期 GPUI fix1**，来自第 16 号本机报告，**没有对本次 visual-fix4 重测**。不能将这些百分比当成本次二进制的性能保证。

两版各稳定等待 60 秒，再采集 60 个空闲样本；硬件/OS/驱动字段匹配，但电源、后台负载和可见夹具未完全控制。单位为 MiB（1 MiB = 1,048,576 字节）。

| 阶段与指标（均值） | Tauri 0.1.3 | GPUI fix1 | 观察到的下降 |
| --- | ---: | ---: | ---: |
| 启动后空闲：私有字节 | 184.67 MiB | 74.44 MiB | 59.69% |
| 启动后空闲：累加工作集 | 379.28 MiB | 51.23 MiB | 86.49% |
| 使用工具后空闲：私有字节 | 364.13 MiB | 165.22 MiB | 54.63% |
| 使用工具后空闲：累加工作集 | 677.59 MiB | 61.65 MiB | 90.90% |

工作集按进程相加可能重复计算共享页；两版空闲 CPU 均为 0%，无法计算“CPU 提升百分比”。冷启动/首帧、交互延迟、GPU/显存与长期循环稳定性尚无可发布的量化收益，不宣称启动更快多少。

## 验证状态与已知限制

- 发布 CI 修正 HTTP 合成测试夹具在 Windows 继承非阻塞状态的兼容问题，保留全部断言；不修改应用请求逻辑。
- 本次发布 CI 的 Windows fmt、全目标 Clippy、64 项仓库测试、MSVC Release、候选工具 20 项、包验证及保留旧版适配层编译通过；GPUI 独立锁文件审计通过（868 项依赖，8 项维护状态警告）。
- 用户 visual-fix4 Windows 验证：fmt、全目标 Clippy、MSVC Release、68 项测试、候选 PowerShell 工具夹具 20 项和重打包通过。68 项包含本机私有验收测试 4 项；仓库不含该私有文件，CI 实际测试数单独记录。
- 已测按钮等高、英语重置/首次回滚、保存失败保留预览、限定 IME/固定失焦/清理及四色复制路径正常。实屏证据属于对应本机构建；CI 重建即使源码一致，二进制哈希也可能不同。
- GPUI 锁文件单独审计；保留的旧 Tauri 锁文件另有依赖审计失败，不能将本次 GPUI 检查写成整个仓库无漏洞。旧 GUI 不进入本次 GPUI 安装包。
- 完整八语言、保存期间禁用/加载瞬态、125/150/200% DPI、更多几何/生命周期与 V-02/V-03 重复矩阵仍待补齐。
- 精确取消零捕获/零剪贴板写入、多屏负坐标/混合 DPI/竖屏、隔离安装/升级/回退/卸载及无 WebView2 环境未完整验收。NSIS 哈希和静态包校验不代表安装行为通过。
- 拖动期间模糊消失、松手恢复仍作为体验反馈保留。

## 使用与证据

先正常退出旧 QuickPick。便携版解压到独立目录后可用 `quickpick.exe --candidate` 试用；该模式不接管正式自启动，但仍需按既有流程备份/恢复配置，不等于配置完全隔离。快捷键：Alt+0 设置、Alt+2 划词、Alt+3 截图、Alt+4 输入翻译。不要在未备份的正式安装上进行升级实验。
