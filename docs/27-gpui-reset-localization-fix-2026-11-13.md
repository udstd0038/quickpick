## 修复依据与实现

`SettingsForm::new` 原来用传入配置的 `ui_language` 生成下拉标签，而页面标签使用已保存的界面语言。重置传入默认配置，其语言为跟随系统；当系统语言为中文、已保存界面为英语时，会产生中文选项。关闭回滚只更新外观控件选中值，沿用原选项标签，所以深色值也可能仍显示中文。

- 表单构建显式接收当前页面显示语言，与配置草稿中的选中语言分开。首次构建、保存成功重建使用已保存语言；重置仍显示当前已保存语言，草稿语言值仍恢复默认。
- 下拉选项 ID 和翻译映射集中为可独立测试的 UI 函数，选项内容与顺序保持原值。外观回滚沿用相同显示语言生成的选项；保存成功后按新的已保存语言重建。
- 重置按钮高度设为 32 DIP，与保存按钮一致；仍为右侧图标按钮，保留本地化 tooltip、鼠标隔离、禁用规则与回调。
- 不改配置结构、重置的默认配置范围或落盘时机。重置仍只改草稿；预览不能应用未保存业务设置。没有修改材质生命周期、窗口命中、捕获/复制、密钥和请求链。
