## 未修复的应用缺陷

**W-01：成功正文首尾空白被裁剪。**

验收约定要求成功文本原样显示。回环服务返回含四个前导空格及末尾换行的固定合成正文，真实 `run_text_action` 返回值与其不一致。`crates/quickpick-core/src/ai.rs` 的文本、输入和图片三个完成路径均调用 `content.trim().to_string()`；本轮完整 HTTP 复现针对文本路径。

```powershell
cargo test -p quickpick-core --test full_acceptance successful_response_preserves_leading_indentation_and_trailing_newline --locked --target-dir target/gpui-candidate
```

结果：退出码 101，断言“成功文本的缩进或末尾换行被修改，违反原样显示验收项”。记录不输出响应正文。用例未忽略，应用代码未改写，因此当前 `build-gpui.ps1` 会在这项新增测试失败时停止；应先处理此缺陷再生成下一轮验收包。
