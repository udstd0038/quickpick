# GPUI 全界面外观候选

本轮按已确认方案复刻旧版结构并优化细节：设置、划词、结果、输入翻译和截图工具栏统一浅深主题；新增外观即时预览。基线为 fix2，旧 GUI 和正式安装保留；[第 28 号 Windows 报告](28-windows-visual-fix4-retest-2026-11-13.md)确认 visual-fix4 按钮等高、英语重置及首次回滚修复在已测路径通过。当前保留该应用基线，完整验收仍未通过；[剩余矩阵](29-gpui-remaining-acceptance-2026-11-13.md)优先补证，不为文档更新生成新应用候选。

## 当前实现

- 集中视觉层使用旧版最终玻璃配色：浅色蓝白、深色石墨，Segoe UI 13–14 DIP、4/8/12/16 间距与 8 DIP 主圆角。复用应用品牌 PNG 和按需 Kit 图标；无新字体、WebView、组件或 Cargo 依赖。
- 设置默认/最小 420×600 DIP；品牌标题栏提供最小化、最大化/还原和关闭。隐藏/最小化后重开恢复默认尺寸，仍可见的窗口不重置用户尺寸。顶部单行七分类含横向滚动条及选中项露出，分类内容独立纵向滚动，状态/保存区固定底部。
- 划词 480×58 DIP：主动作与固定/关闭同一行；通过实际字体排版宽度决定图标加文案或带 tooltip 的纯图标；空白可拖动，按钮阻止拖动事件冒泡。复制/搜索失败在紧凑错误图标 tooltip 中显示，主动作仍可重试。
- 结果/输入默认 480×460 DIP：翻译方向居中，固定/关闭使用线性图标，固定态高亮；非翻译结果显示对应标题。输入区 96 DIP，结果区伸缩并裁剪，底部翻译/复制；结果成功态只留复制，错误态提供重试。加载使用局部 Skeleton，成功文本区域 140ms 淡入，不修改正文。
- 截图工具栏使用单层玻璃表面、主题化边框/句柄及普通箭头光标；物理选区转换、命中、提交、隐藏和捕获链不变。
- 语言变更保存后更新已有工具窗口下拉文案，保留选中语言值；不因重新本地化控件而提交 AI。

## 即时预览的约束

`AppearanceDraft` 与 `AppearancePreview` 为内存类型，只有主题、材质和不透明度，不增加持久化字段。表单预览直接读取这三项，不要求其他未完成字段合法，也不把业务草稿传给 AI。

- 设置修改立即更新应用统一视觉状态及普通窗口材质。原生 Mica/Acrylic 和窗口底色透明度沿用原路径；配置 alpha 只应用于窗口根底色，普通卡片/输入框/默认按钮背景透明，交互状态和前景独立绘制。
- 保存成功以新设置为回滚目标；失败保留当前预览和错误信息。关闭/隐藏设置、转入取词或截图时回滚并重置三个外观控件；最小化保留预览。其他非敏感业务草稿保持原表单行为，密钥仍按原关闭链清理。
- 系统主题事件按当前有效模式处理；“跟随系统”由协调器统一刷新，不让各工具窗口用自己的已保存快照反复覆盖全局主题。
- 截图窗口不参与普通材质/不透明度预览，根背景始终透明；预览不创建屏幕纹理、不捕获、不调用 AI。

## Windows 复测顺序

先正常退出 fix2 和旧版，在本轮全新 snapshot 中保留原本机 `full_acceptance.rs`，执行：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\build-gpui.ps1 -Launch
powershell -ExecutionPolicy Bypass -File scripts\verify-hotkeys.ps1
```

1. 设置七分类和保存区可达；中英文浅深主题对照，八语言长标签不溢出；100/125/150/200% DPI，最大化/还原、隐藏/最小化后重开尺寸。
2. 主题/材质/透明度即时预览：普通工具一起变化、截图仍透明；关闭未保存恢复、最小化保留、保存持久化；用合成夹具制造保存失败后预览仍在。未保存模型/URL/快捷键不得因外观预览生效。
3. Tab、Enter、Esc 与鼠标悬停/按压；输入真实 IME/Ctrl+Enter、长文本滚动/复制、固定/失焦；按钮按下不拖动窗口，不触发截图框选。
4. S5-01 先显式运行原合成剪贴板 example，再测试实际 GUI 框选复制；复制结果使用纯合成四色窄带验证无工具栏/边框/暗化。Enter 不能提交，取消仍不应读取像素或写剪贴板；已有受控证据缺口不关闭。
5. 正常退出候选后重新 `build-gpui.ps1 -Package` 并运行包校验，生成新 EXE/ZIP/NSIS 哈希；不沿用 fix2 产物。

安装隔离环境、多屏设备、取消剪贴板受控证据和其他阶段 5 待办继续单列。本轮不修改托盘系统绘制，不删除旧前端，不切换正式发行。
