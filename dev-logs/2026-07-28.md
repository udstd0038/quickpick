- “设置面板缩小到原本四分之一”按面积理解，采用窗口宽高各缩小到约一半的方案。
- 通过 CSS `0.5` 等比缩放设置页，而不是逐项压缩字号和间距，减少布局回归风险。
- 上一轮曾将托盘菜单字号单独处理；本轮已按用户最新要求撤回。
- 用户明确要求“设置页回调到上一个版本”后，仅回退设置页尺寸和缩放；后续托盘字体已按最新要求恢复常规字号。
- 用户明确要求托盘右键菜单字体改为其他原生弹窗字号后，撤回托盘专用小字号，恢复共用原生弹窗 `UI_FONT_SIZE`。
- 本次前端重设计仅覆盖设置页 Web 前端，不改划词、截图、AI 请求、托盘菜单绘制和结果弹窗的运行行为。
- 设置页采用更偏工程控制台的紧凑信息布局，避免装饰性插画、强渐变和大面积营销式卡片。
- 用户要求“回退到上一个版本”后，本次只撤回最近一次前端重设计，不改此前已验收的划词、截图、AI、托盘和结果窗口逻辑。
- 深色设置页实际使用 `data-theme="workbench"`，但保留 `dark` 选择器兼容旧配置和系统跟随路径。
- 本次继续只调整设置页顶部状态胶囊数值，不修改 DOM 结构和业务逻辑。
- 浅色状态胶囊改用固定高度和 `max-height`，避免基础 `.status-pill` 的 `min-height` 与继承行高继续放大视觉尺寸。
