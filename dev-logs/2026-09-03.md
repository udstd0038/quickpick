# 2026-09-03 开发日志

## 今日完成

- 修复设置页在不同电脑/不同 DPI 下窗口尺寸不一致的问题。
- `main` 窗口从 `tauri-plugin-window-state` 的状态记忆中排除，旧 `.window-state.json` 不再恢复设置页尺寸。
- 设置页从隐藏或最小化状态重新打开时，强制重置为逻辑尺寸 `420x600`，保留用户可手动放大的能力。
- 新增默认尺寸 helper 与 Rust 单测，确保默认值不会漂移。
- 修复已提交到 `feature/macos-port`：`dfc0cca`；`main` 分支同步实施同一修复。

## 关键决策

- 继续使用逻辑尺寸而非物理尺寸，避免不同系统缩放比例导致窗口比例变化。
- 不删除用户现有窗口状态文件，只让设置页不再使用其中的 `main` 状态。

- 前端测试 29/29 通过。
