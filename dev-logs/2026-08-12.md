# 2026-08-12 追加开发记录 - 默认安装位置调整

## 今日完成

- 自定义 NSIS 安装路径：优先安装到 `D:\Program Files\QuickPick`。
- 无 D 盘时自动选择其他非系统盘的 `Program Files\QuickPick`；只有 C 盘时回退到 `C:\Program Files\QuickPick`。
- 安装模式从 `currentUser` 调整为 `perMachine`，以匹配 Program Files 的写入权限。

## 关键决策

- 默认安装路径采用固定盘扫描，不依赖 Tauri 默认的 `$LOCALAPPDATA` 或当前系统 Program Files 变量。
- 对 64 位应用统一使用字面量 `Program Files`，不进入 `Program Files (x86)`。

## 验证结果

- NSIS 构建通过，生成新的 `QuickPick_0.1.0_x64-setup.exe`。

## 待办

- 人工在 D 盘、无 D 盘和仅 C 盘环境安装一次，确认默认路径符合预期。
