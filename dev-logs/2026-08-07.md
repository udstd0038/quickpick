# 2026-08-07 开发日志

## 今日完成

- 新增输入翻译功能（规划版）：默认 `Alt+4` 呼出原生 Win32 单窗输入翻译弹窗。
- 设置页 AI 导航由单一 `ai` 项拆分为“划词模型、截图模型、输入模型”三个独立导航项，每项一张独立 AI 配置卡片。
- `AppSettings` 新增输入翻译快捷键、输入模型供应商/Base URL/模型、默认源语言和目标语言字段，并纳入保存归一化与快捷键冲突校验。
- `security.rs` 新增 `input` scope，使用独立 DPAPI 文件保存输入模型 API Key。
- `ai.rs` 新增输入模型调用链，复用 OpenAI chat/completions 请求、12000 字限制、超时和错误提示，不复用划词/截图模型。
- 原生输入弹窗实现多行编辑框、源语言/目标语言/方向控件、翻译按钮、Skeleton 加载态、复制/固定/关闭和同窗结果更新；语言切换后使用当前输入文本重新请求。
- 设置页新增输入模型卡片：供应商、Base URL、模型、API Key、快捷键、默认源语言、默认目标语言。
- 更新产品需求、路线图、UI 规范、安全隐私和测试验收文档。

## 关键决策

- 输入翻译使用原生 Win32 单窗输入+结果，不创建 Tauri/WebView 子窗口，规避白窗问题。
- 输入模型配置完全独立，不复用划词文本模型或截图视觉模型，避免误用密钥。
- 输入文本由弹窗事件携带到异步请求线程，不写入共享状态或历史文件。

## 遇到问题
